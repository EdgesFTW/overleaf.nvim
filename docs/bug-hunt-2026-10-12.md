# Bug hunt, 2026-10-12

Five read-only audits (OT core; buffer and change detection; bridge, protocol
and auth; commands and project structure; and an advisor's read of the pending
specs) plus the lead's own checks. Each finding carries how it was verified:

- **lead-reproduced:** the lead ran it.
- **auditor-reproduced:** an auditor ran a headless script.
- **traced:** read through the code paths, not run.

Fix status is kept here as batches land.

Already covered elsewhere and not repeated here:
`docs/mirror-agent-safety-spec.md` (disk mirror, file tree order) and
`docs/undo-own-edits-spec.md` (undo reverting collaborators).
